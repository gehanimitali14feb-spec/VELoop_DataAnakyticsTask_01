## 1. Event Architecture & Naming Standard
All event names strictly follow the **`object_action`** standard (e.g., `user_registered`, `task_completed`, `reward_credited`)[cite: 14, 15, 40].

### Universal Base Payload
Every event emitted must include:
* `event_id`: Unique UUIDv4 string[cite: 54]
* `user_id`: Permanent user ID (`VLUSR...`)[cite: 7, 54]
* `session_id`: Active session identifier[cite: 7, 54]
* `event_name`: Standardized event string (`object_action`)[cite: 15, 54]
* `timestamp`: ISO-8601 UTC timestamp[cite: 54]
* `device` & `platform`: User environment (`Android`, `iOS`, `Web`)[cite: 54]

## 2. Core Event Telemetry Catalogue (By Feature Domain)

* **Authentication & Onboarding:**  
  * `user_registered`: Fired when a new user record is created[cite: 14, 54].  
  * `user_logged_in`: Fired when an authentication token is issued[cite: 14, 54].  
  * `user_logged_out`: Fired upon explicit session termination[cite: 14, 54].  
  * `onboarding_started`: First welcome screen viewed[cite: 14, 54].  
  * `onboarding_completed`: Final onboarding tutorial step completed[cite: 14, 54].  

* **Earning & Tasks:**  
  * `task_viewed`: Task/offer card rendered in offerwall feed[cite: 14, 54].  
  * `task_opened`: User taps task card for details[cite: 14, 54].  
  * `task_started`: Outbound partner link clicked or activity launched[cite: 14, 54].  
  * `task_completed`: User satisfies completion requirements[cite: 14, 54].  
  * `task_failed`: Task times out, errors, or fails validation[cite: 14, 54].  

* **Watch Ads & Minigames:**  
  * `ad_started`: Video ad player begins playback[cite: 54].  
  * `ad_completed`: Video ad reaches 100% completion[cite: 54].  
  * `ad_skipped`: User skips ad playback[cite: 54].  
  * `tap_started` & `tap_completed`: Tap & Earn activity bounds[cite: 54].  
  * `spin_started` & `spin_completed`: Wheel spin minigame execution and prize payout[cite: 14, 54].  
  * `mining_started` & `mining_stopped`: Mining session duration tracking[cite: 54].  

* **Gamification & Retention:**  
  * `daily_reward_viewed`: Check-in modal viewed[cite: 54].  
  * `daily_reward_claimed`: Daily check-in claimed (max 1 per 24h)[cite: 14, 54].  
  * `streak_claimed`: Milestone streak reward achieved[cite: 54].  
  * `streak_broken`: User missed 24h window; streak reset[cite: 54].  
  * `mission_started` & `mission_completed`: Periodic quest tracking[cite: 14, 54].  
  * `badge_earned`: Milestone badge unlocked[cite: 14, 54].  
  * `level_up`: XP threshold crossed to next level tier[cite: 54].  

* **Referrals & Payouts:**  
  * `referral_created`: Invite code/link shared[cite: 15, 54].  
  * `referral_registered`: Referee signs up using code[cite: 15, 54].  
  * `referral_converted`: Referee hits qualifying milestone; bonus unlocked[cite: 15, 54].  
  * `withdrawal_requested`: Cashout request submitted by user[cite: 15, 54].  
  * `withdrawal_completed`: Gateway confirms payout settled[cite: 15, 54].

## 3. Data Integrity & Deduplication Rules
1. **Event Deduplication:** Drops duplicate `event_id` records received within a 24-hour window[cite: 54].  
2. **Transaction Idempotency:** Balance updates require a unique `idempotency_key` (`user_id + event_name + date`) to prevent double-crediting[cite: 24, 54].  
3. **Client Debouncing:** Disables action buttons immediately upon click to prevent rapid duplicate taps[cite: 54].
