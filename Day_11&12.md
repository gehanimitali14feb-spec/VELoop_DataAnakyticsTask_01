# Days 11–12: Referral Funnel & Production Event Tracking Plan
**Work Package Reference:** Work Packages E & F  
**Deliverable:** 4-Stage Referral Conversion Funnel & 25 Core Production Telemetry Events  
**Mandatory Authenticity Policy:** Telemetry event naming follows strict production standards (`object_action`).

---

## 1. Referral Attribution Funnel (WP E)
Referrals are tracked across four explicit milestone stages:

$$\text{Referral Created} \longrightarrow \text{User Registered} \longrightarrow \text{User Activated} \longrightarrow \text{Referral Converted}$$

* **Referral Created (`referral_created`):** User shares custom referral link or code (`referral_code`).
* **User Registered (`referral_registered`):** New referee signs up with a valid code linked to the referrer (`referrer_id`).
* **User Activated (`referral_activated`):** Referee reaches minimal qualifying usage (completing at least 1 verified task).
* **Referral Converted (`referral_converted`):** Reward conditions met; referral bonus unlocked and posted to the referrer's wallet.
